= Installing Kubernetes NMState

[role="_abstract"]
Install the Kubernetes NMState Operator and create an `NMState` instance. The
procedures in this assembly use `NodeNetworkConfigurationPolicy` resources to
create OVS bridges, Linux bridges, bonds, and macvlan interfaces.

.Prerequisites

* You have cluster-admin access to the cluster.
* The cluster can pull images from the Red Hat Operators catalog.

.Procedure

. Create the operator namespace:
+
[source,terminal]
----
$ oc create namespace openshift-nmstate
----

. Create a subscription for the Kubernetes NMState Operator:
+
[source,yaml]
----
apiVersion: operators.coreos.com/v1alpha1
kind: Subscription
metadata:
  name: kubernetes-nmstate-operator
  namespace: openshift-nmstate
spec:
  channel: stable
  name: kubernetes-nmstate-operator
  source: redhat-operators
  sourceNamespace: openshift-marketplace
  installPlanApproval: Automatic
----
+
You can also install the operator from the software catalog in the OpenShift
Container Platform web console.

. Wait for the operator to install:
+
[source,terminal]
----
$ oc get csv -n openshift-nmstate \
    -o custom-columns=NAME:.metadata.name,PHASE:.status.phase
----
+
The phase must be `Succeeded` before you continue.

. Create the `NMState` instance:
+
[source,yaml]
----
apiVersion: nmstate.io/v1
kind: NMState
metadata:
  name: nmstate
----
+
Apply the resource:
+
[source,terminal]
----
$ oc apply -f nmstate.yaml
----

.Verification

. Confirm that the `NMState` instance is available:
+
[source,terminal]
----
$ oc get nmstate nmstate \
    -o custom-columns=NAME:.metadata.name,AVAILABLE:.status.conditions[?(@.type=="Available")].status
----
+
The `AVAILABLE` column must show `True`.

. Confirm that the NMState handlers are running on the worker nodes:
+
[source,terminal]
----
$ oc get pods -n openshift-nmstate
$ oc get nncp
$ oc get nnce
----
+
The `nmstate-handler` pods run as a DaemonSet on the nodes. `nncp` and `nnce`
are empty until you create a `NodeNetworkConfigurationPolicy`.
