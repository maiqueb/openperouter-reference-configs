= Connecting workloads to an EVPN secondary network with OpenPERouter
:context: virt-connecting-workloads-to-evpn-secondary-networks
:oc-first: oc

[role="_abstract"]
You can connect pods and virtual machines on an OpenShift cluster to an
external Layer 2 segment by running OpenPERouter on the worker nodes. The
workload segment is stretched over VXLAN and advertised over BGP EVPN, so an
external router and its clients can reach the workloads by IP address. When you
follow this guide, you create an EVPN/VXLAN secondary network carrying
workload traffic across this extended layer 2 segment, using any of the
physical network options described in
xref:workload-attachment-models_{context}[Workload attachment models]:

* OVN-Kubernetes localnet topology on a dedicated bridge
* OVN-Kubernetes localnet topology sharing `br-ex`
* A dedicated Linux bridge

toc::[]

The procedures follow the dependency order of the components: install the
operators, prepare the node underlay and the external router, define the
Layer 3 and Layer 2 VNIs, then attach pods and virtual machines.
