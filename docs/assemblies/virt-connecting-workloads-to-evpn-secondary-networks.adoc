= Connecting workloads to an EVPN secondary network with OpenPERouter
:context: virt-connecting-workloads-to-evpn-secondary-networks
:oc-first: oc
:openperouter-version: 4.22.0

[role="_abstract"]
You can connect virtual machines on an OpenShift cluster to an
external Layer 2 segment by running OpenPERouter on the worker nodes. The
workload segment is stretched over VXLAN and advertised over BGP EVPN, so an
external router and its clients can reach the workloads by IP address. When you
follow this guide, you create an EVPN/VXLAN secondary network carrying
workload traffic across this extended layer 2 segment, using one of the uplink
layouts described in
xref:proc-configuring-the-uplink_{context}[Uplink configuration] and one of the
workload attachment models described in
xref:workload-attachment-models_{context}[Workload attachment models]:

* Sharing the default interface for the uplink
* Using a dedicated interface for the uplink
* An OVN-Kubernetes localnet bridge for workloads
* A Linux bridge for workloads

toc::[]

The procedures follow the dependency order of the components: install the
operators, configure the uplink and the workload bridge, then apply the
complete examples that define the Layer 3 and Layer 2 VNIs and attach virtual
machines.
